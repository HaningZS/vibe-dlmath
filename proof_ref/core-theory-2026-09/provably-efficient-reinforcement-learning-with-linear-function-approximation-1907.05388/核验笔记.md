## 用于模板的结论

- 证明链是 self-normalized good event → backward optimism → per-episode Bellman error → bonus/elliptical-potential sum。
- Occupancy、真实 Bellman operator、算法执行策略与估计 value 必须分别定义。

## 不可迁移边界

- 主结果依赖 linear MDP 结构、bounded features/rewards、明确 bonus 与 horizon；不能把任意 embedding 当作 realizable linear MDP。
- Misspecification 产生额外 bias；offline pessimism 不是该 online theorem 的直接推论。
