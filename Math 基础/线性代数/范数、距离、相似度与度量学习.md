# 范数、距离、相似度与度量学习

证明进阶：[T45 扰动范数、Lipschitz margin 与认证半径](../../proofs/generalization/T45-certified-robustness.md)。

与学习保证的连接：[T35 归一化间隔与范数泛化](../../proofs/generalization/T35-margin-norm.md)。

先抓住一句话：

> 范数给一个向量量“大小”，距离比较两个对象隔多远，相似度比较它们有多像；三者可以互相构造，但不是同一个概念。

在 embedding、attention、CLIP、RAG 和对比学习里，“最相似”看似是一句直观的话，实际已经偷偷选择了几何规则。选择 dot product、cosine、L2 或 Mahalanobis，会改变什么叫近邻、什么方向重要，以及模型能否通过单纯增大向量长度提高得分。

## 1. 范数：一把衡量“多大”的尺子

向量范数 $\|x\|$ 至少满足：

1. 非负，且只有零向量的范数为 0；
2. 齐次性：$\|\alpha x\|=|\alpha|\,\|x\|$；
3. 三角不等式：$\|x+y\|\le\|x\|+\|y\|$。

第三条的人话是：直接从起点走到终点，不会比故意绕路更长。

最常见的 $p$-范数为

$$
\|x\|_p=\left(\sum_i|x_i|^p\right)^{1/p},
\qquad p\ge1.
$$

- $L_1$：所有坐标绝对值相加，像城市街区只能横竖走；
- $L_2$：欧氏直线距离；
- $L_\infty$：只看绝对值最大的坐标。

$0<p<1$ 时同样可以写出上述表达式，但它不满足三角不等式，因此是 quasi-norm，不是严格范数。$L_0$ 常被口语化为“非零元素个数”，它也不是范数。

### 范数不是坐标无关的唯一真相

换一个坐标尺度，距离判断会变。例如一个特征用米、另一个用毫米，直接 L2 会让毫米坐标的数值占主导。标准化、白化或学习一个度量，本质上都在重新定义哪些方向应该付出多少距离。

## 2. 距离：比较两个对象隔多远

严格的度量 $d(x,y)$ 满足：

1. $d(x,y)\ge0$；
2. $d(x,y)=0$ 当且仅当 $x=y$；
3. 对称：$d(x,y)=d(y,x)$；
4. 三角不等式。

任意范数都能诱导距离：

$$
d(x,y)=\|x-y\|.
$$

但研究中常把“distance”用得更宽松。例如 KL 散度不对称，也不满足一般的三角不等式，所以严格说不是距离；它仍然是有用的分布差异量。

## 3. 点积和余弦：大小与方向要不要分开

欧氏内积满足

$$
x^\top y=\|x\|_2\|y\|_2\cos\theta.
$$

因此 dot product 同时看两件事：

- 两个向量是否朝向相近；
- 两个向量本身有多长。

余弦相似度把长度除掉：

$$
\operatorname{cos}(x,y)
=\frac{x^\top y}{\|x\|_2\|y\|_2},
$$

只比较方向。它通常落在 $[-1,1]$，前提是两个向量非零。

类比：dot product 同时考虑两支箭的方向和推力，cosine 只问箭头是否朝同一边。

### 什么时候 dot 和 cosine 排序相同

若所有候选向量都已 L2 归一化，且 query 也归一化，则

$$
x^\top y=\operatorname{cos}(x,y).
$$

若候选长度不同，dot product 可能偏爱更长的向量，即使方向更差。这个偏好可能有意义，也可能只是 embedding norm 的副作用，必须结合训练目标判断。

## 4. 单位球面上，cosine 与 L2 是同一排序

当 $\|x\|_2=\|y\|_2=1$：

$$
\|x-y\|_2^2
=\|x\|^2+\|y\|^2-2x^\top y
=2-2\operatorname{cos}(x,y).
$$

所以在单位球面上：

- 最大化 cosine；
- 最大化 dot product；
- 最小化平方 L2 距离；

三者给出相同的近邻排序。数值分数不同，但排序等价。

这解释了为什么 CLIP 一类模型常先归一化图像和文本表示，再用点积配合可学习温度。归一化把“向量多长”从比较中拿掉，温度再控制 logits 的整体尺度。

## 5. 相似度不一定是距离的简单反号

常见相似度包括：

- dot product：$s(x,y)=x^\top y$；
- cosine：方向相似；
- Gaussian/RBF kernel：$\exp(-\|x-y\|^2/(2\sigma^2))$；
- learned score：神经网络根据一对表示输出分数。

把距离写成 $-d(x,y)$ 可以得到一个“越大越像”的分数，但不意味着所有相似度都能反推出严格度量。

例如 dot product 的自相似 $x^\top x$ 会随长度变化，也不满足距离公理。论文写“similarity”时应先找公式，不要只凭词语推断几何性质。

## 6. Mahalanobis 距离：不同方向使用不同刻度

给定对称正定矩阵 $M\succ0$：

$$
d_M(x,y)
=\sqrt{(x-y)^\top M(x-y)}.
$$

若 $M=I$，就是普通 L2。若 $M=\Sigma^{-1}$，则高方差方向被降权、低方差方向被放大，因为在稳定方向上的小偏离可能更异常。

把 $M=L^\top L$ 分解后：

$$
d_M(x,y)=\|L(x-y)\|_2.
$$

所以学习 Mahalanobis 度量等价于先学习一个线性变换，再在变换后的空间使用 L2。

如果 $M$ 只有半正定，则某些非零方向距离可能为 0，得到的是 pseudometric；若协方差奇异，也不能不加处理就直接求逆，见 [投影、最小二乘与伪逆](%E6%8A%95%E5%BD%B1%E3%80%81%E6%9C%80%E5%B0%8F%E4%BA%8C%E4%B9%98%E4%B8%8E%E4%BC%AA%E9%80%86.md) 与 [浮点数、数值稳定性与条件数](../%E6%95%B0%E5%80%BC%E8%AE%A1%E7%AE%97/%E6%B5%AE%E7%82%B9%E6%95%B0%E3%80%81%E6%95%B0%E5%80%BC%E7%A8%B3%E5%AE%9A%E6%80%A7%E4%B8%8E%E6%9D%A1%E4%BB%B6%E6%95%B0.md)。

## 7. 度量学习：不是寻找宇宙唯一距离

度量学习用任务监督塑造表示，使“应该接近”的样本更近，“应该分开”的样本更远。常见形式包括 contrastive loss、triplet loss、InfoNCE 与分类式代理目标。

一个 triplet 直觉是：anchor $a$ 应比 negative $n$ 更靠近 positive $p$：

$$
d(a,p)+m\le d(a,n),
$$

其中 $m$ 是 margin。

但学到的不是语义世界的客观真理，而是由数据、正负样本构造、增强方式和 loss 定义出来的任务几何。改变“谁算正样本”，几何也会改变。

## 8. Temperature：控制区分度，不创造新信息

对相似度 logits $s_i$，softmax 常写成

$$
p_i=\frac{\exp(s_i/\tau)}{\sum_j\exp(s_j/\tau)}.
$$

- $\tau$ 小：logits 差异被放大，分布更尖；
- $\tau$ 大：分布更平。

temperature 改变损失对难负样本和相似度差异的敏感度，也改变梯度尺度；它不会凭空让错误的正负样本变正确。若 embedding 未归一化，模型还可能通过改变 norm 与 temperature 共同调节 logit 尺度。

## 9. Attention 为什么使用 scaled dot product

若 $q_i,k_i$ 近似独立、均值为 0、方差为 1，则

$$
q^\top k=\sum_{i=1}^d q_i k_i
$$

的方差约随 $d$ 增长。除以 $\sqrt d$ 后，logit 的典型尺度在这个简化假设下保持 $O(1)$，能减少 softmax 过早饱和。

这是初始化尺度的统计直觉，不是对训练后所有 attention head 的精确分布定理。LayerNorm、权重初始化、相关性和训练都会改变假设。

## 10. 可运行示例：归一化怎样改变近邻

```python
import numpy as np

query = np.array([1.0, 0.0])
candidates = np.array([
    [0.8, 0.6],   # 与 query 的夹角较小，长度为 1
    [3.0, 4.0],   # 方向更差，但长度为 5
])

dot_scores = candidates @ query
candidate_norms = np.linalg.norm(candidates, axis=1)
cosine_scores = dot_scores / (candidate_norms * np.linalg.norm(query))

normalized = candidates / candidate_norms[:, None]
l2_on_sphere = np.linalg.norm(normalized - query, axis=1)

print("dot:", dot_scores)
print("cosine:", cosine_scores)
print("L2 after normalization:", l2_on_sphere)

# dot 偏爱更长的第二个向量；cosine 更喜欢方向更近的第一个。
assert np.argmax(dot_scores) == 1
assert np.argmax(cosine_scores) == 0

# 单位球面上，最大 cosine 与最小 L2 给相同排序。
assert np.argmax(cosine_scores) == np.argmin(l2_on_sphere)
assert np.allclose(l2_on_sphere**2, 2.0 - 2.0 * cosine_scores)

# Mahalanobis：第二个坐标噪声大，因此降低该方向权重。
x = np.array([1.0, 2.0])
y = np.array([0.0, 0.0])
covariance = np.diag([1.0, 16.0])
precision = np.linalg.inv(covariance)
mahalanobis = np.sqrt((x - y) @ precision @ (x - y))
euclidean = np.linalg.norm(x - y)
print("Euclidean / Mahalanobis:", euclidean, mahalanobis)
assert mahalanobis < euclidean
```

## 常见误区

1. **“cosine 高就表示语义一定相同。”** cosine 只反映当前表示空间中的方向；表示是由训练数据和目标塑造的。
2. **“归一化只是数值技巧。”** 它会删除 norm 信息并改变模型可表达的打分规则，是建模选择。
3. **“L1、L2 只是两种近似写法。”** 它们的单位球、鲁棒性和优化行为不同。
4. **“Mahalanobis 自动更科学。”** 协方差估计不稳、样本少或分布漂移时，它也会误导。
5. **“KL distance 是一种普通距离。”** KL 有方向且一般不满足三角不等式。
6. **“temperature 越小，表示越好。”** 太小会造成过尖分布、梯度集中或训练不稳；需要与 batch、负样本和归一化共同调节。
7. **“attention 除以 $\sqrt d$ 是永远精确的方差校正。”** 它来自简化初始化假设，是稳定尺度设计，不是训练后分布恒等式。
