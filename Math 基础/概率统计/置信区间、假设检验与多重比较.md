# 置信区间、假设检验与多重比较

证明进阶：[T45 随机平滑认证的有限采样条件](../../proofs/generalization/T45-certified-robustness.md)，展示为什么类别选择与同时概率界要配合。

“模型 A 比 B 高 0.7 分”只是这批数据上的结果。统计推断真正要问的是：这种差异有多不稳定？如果总体没有差异，看到这么极端的结果有多意外？同时尝试了很多指标、数据集和 seed 后，偶然胜出的概率有多大？

置信区间负责表达估计精度，假设检验负责衡量数据与某个基准假设的冲突程度，多重比较负责阻止“试得越多，中奖越容易”被误当成发现。它们都是**决策证据**，不是自动真理机器。

## 1. 先分开“效应大小”和“证据强度”

假设模型 A 准确率比 B 高 $0.5$ 个百分点：

- **效应大小**： $0.5$ 个百分点，回答“差多少”；
- **标准误/区间宽度**：回答“这个差值估得多准”；
- **p 值**：在特定零假设下，回答“这样的数据有多反常”；
- **实际意义**：回答“这点提升是否值得成本、延迟或风险”。

大样本可让极小效应“统计显著”，小样本也可能让有价值的效应暂不显著。不要用一个 p 值替代全部判断。

## 2. 置信区间：会覆盖真值的随机程序

对参数 $\theta$，95% 置信区间由样本随机生成。它的严格频率学解释是：**如果按同一数据生成和构造流程无限重复，得到的区间约有 95% 会覆盖固定真值。**

在已观察数据下，经典频率学参数不是随机变量，所以不能直接说“真值有 95% 概率落在这个已经固定的区间里”。想做参数概率陈述，需要明确贝叶斯后验和可信区间。

### 2.1 均值的近似区间

样本近似独立、样本量适当时：

$$
\bar x\pm z_{1-\alpha/2}\frac{s}{\sqrt n}.
$$

95% 区间常用 $z_{0.975}\approx1.96$；小样本正态数据用 t 分布临界值。若数据强偏斜、重尾或相关，需要更合适的方法。

### 2.2 配对设计通常更有力

比较两个模型时，最好让它们评测**同一批样本**。令每个样本上的指标差为

$$
d_i=m_A(x_i)-m_B(x_i).
$$

对 $\bar d$ 构造区间可利用样本内相关性；这通常比把 A、B 当两组独立结果更精确。对准确率差，可用配对 bootstrap、置换检验或 McNemar 检验，具体取决于指标与问题结构。

### 2.3 Bootstrap：让样本近似扮演总体

非参数 bootstrap 的基本过程：

1. 从原始 $n$ 个独立单位中有放回抽 $n$ 个；
2. 计算目标统计量；
3. 重复很多次，得到经验抽样分布；
4. 用分位数或更精细的校正构造区间。

它适合解析标准误困难的指标，但不是万能的：时间序列需 block bootstrap；同一患者多条记录应按患者重采样；极端分位数、小样本和非光滑统计量需要谨慎。

## 3. 假设检验究竟在做什么

先设零假设 $H_0$（例如“总体平均差为 0”）和备择假设 $H_1$。检验统计量 $T(D)$ 衡量数据偏离 $H_0$ 的程度。

p 值是：

$$
p=P_{H_0}\big(T(D')\text{ 至少与观测结果一样极端}\big).
$$

这里的概率是在**假定 $H_0$ 和检验模型成立**时，对尚未观测的重复数据 $D'$ 计算的。它不是 $P(H_0\mid D)$，也不是“结果由随机性造成的概率”。

### 3.1 两类错误与功效

- 第一类错误： $H_0$ 为真却拒绝它，概率上限常设为 $\alpha$；
- 第二类错误： $H_1$ 为真却没拒绝 $H_0$，概率记作 $\beta$；
- 功效（power）： $1-\beta$，即真实效应存在时检出的概率。

功效取决于样本量、噪声、真实效应大小、显著性阈值和检验设计。研究前做 power analysis，比事后把“不显著”解释成“完全相同”更可靠。

### 3.2 双侧还是单侧

双侧检验关心任一方向的偏离；单侧检验只关心预先指定方向。看到结果方向后才改成单侧，会人为降低 p 值。方向应由研究问题提前决定。

## 4. 区间与检验是同一枚硬币的两面

在匹配的模型和假设下，若双侧 $1-\alpha$ 置信区间不包含零，则对应双侧检验通常在 $\alpha$ 水平拒绝“效应为零”。

区间通常更有信息，因为它同时展示：

- 效应方向；
- 合理大小范围；
- 估计精度；
- 是否排除“几乎无实际意义”的区域。

比起只说 “ $p<0.05$”，更好的报告是：“平均提升 0.7 个百分点，95% CI [0.2, 1.2]，在预先指定的主要指标上……”。

## 5. 多重比较：看得越多，越容易偶然显著

若进行 $m$ 个独立的零假设检验，每个都用 $\alpha=0.05$，至少一次误报的概率为

$$
1-(1-0.05)^m.
$$

$m=20$ 时约为 64%。真实检验常相关，但“挑最小 p 值”仍会严重夸大证据。

### 5.1 控制哪种错误？

- **FWER**：至少一个错误拒绝的概率。Bonferroni 和 Holm 控制它，较保守，适合少量关键结论。
- **FDR**：所有被拒绝假设中，错误发现所占比例的期望。Benjamini–Hochberg（BH）在独立或某些正相关条件下控制它，适合大规模探索；任意依赖下要检查条件，或考虑 Benjamini–Yekutieli 等更保守方法。

Bonferroni 用阈值 $\alpha/m$。Holm 先排序 p 值，再逐步比较，通常不比 Bonferroni 差。BH 将排序后的 $p_{(i)}$ 与 $iq/m$ 比较，并拒绝直到满足条件的最大 $i$。

### 5.2 什么算“一族检验”

不是文件里相邻的 p 值才算一族，而是**共同服务于同一组研究结论、存在选择机会的检验**。多个 benchmark、指标、模型变体、层和时间点都可能构成多重性。

预先指定一个主要终点，把其余标为次要或探索性，可以让结论层级更清楚；但不能靠改名字消除实际选择过程。

## 6. AI 评测中的研究设计建议

1. **定义独立单位**：题目、用户、患者还是视频？按真正独立单位计算误差。
2. **优先配对**：相同样本、相同预处理、相同评审协议比较模型。
3. **报告分子分母**：准确率之外报告样本数、失败类型和区间。
4. **区分两层随机性**：训练 seed 波动与测试样本波动分别处理，必要时使用层级模型。
5. **锁定测试集**：反复看测试结果并据此迭代，会形成隐性多重比较和测试泄漏。
6. **同时看效果与成本**：统计显著不代表工程上值得部署。
7. **探索与确认分开**：探索性结果可以有价值，但应在独立数据上确认。

## 7. 可运行示例：配对 bootstrap 与 BH 校正

```python
import numpy as np

rng = np.random.default_rng(11)

# 同一批 400 个样本上，a 和 b 是否答对；共享 difficulty 造成配对相关。
n = 400
difficulty = rng.normal(size=n)
p_a = 1.0 / (1.0 + np.exp(difficulty - 0.15))
p_b = 1.0 / (1.0 + np.exp(difficulty + 0.05))
a = rng.binomial(1, p_a)
b = rng.binomial(1, p_b)
diff = a - b

# 对“样本对”而非单独的 a/b 有放回抽样。
boot_idx = rng.integers(0, n, size=(20_000, n))
boot_diff = diff[boot_idx].mean(axis=1)
ci = np.quantile(boot_diff, [0.025, 0.975])
print("paired accuracy difference:", diff.mean())
print("percentile bootstrap 95% CI:", ci)

# Benjamini-Hochberg 调整后的 p 值；控制保证还取决于检验间依赖条件。
def bh_adjust(p_values):
    p = np.asarray(p_values, dtype=float)
    order = np.argsort(p)
    ranked = p[order]
    adjusted_ranked = ranked * len(p) / np.arange(1, len(p) + 1)
    adjusted_ranked = np.minimum.accumulate(adjusted_ranked[::-1])[::-1]
    adjusted = np.empty_like(adjusted_ranked)
    adjusted[order] = np.clip(adjusted_ranked, 0.0, 1.0)
    return adjusted

p_values = np.array([0.001, 0.012, 0.020, 0.20, 0.80])
print("raw p-values:", p_values)
print("BH-adjusted:", bh_adjust(p_values))

assert ci[0] <= diff.mean() <= ci[1]
assert np.all(bh_adjust(p_values) >= p_values)
```

这里 percentile bootstrap 便于理解，但复杂研究可考虑 BCa 区间、cluster bootstrap 或基于设计的置换方法。调整后的 p 值也不能替代效应大小与区间。

## 8. 常见误区

1. **“p=0.03 表示零假设为真的概率是 3%。”** 这是把 $P(D\mid H_0)$ 错当成 $P(H_0\mid D)$。
2. **“不显著就证明两个模型相同。”** 可能只是功效不足；若要证明近似等价，应预设实际等价界并做等价检验。
3. **“显著就代表效果大。”** 大样本下微小效应也会显著。
4. **“95% CI 里有 95% 的参数概率。”** 这是贝叶斯可信区间式陈述，不是经典置信区间的严格解释。
5. **“只要最终论文展示一个指标，就没有多重比较。”** 如果曾根据大量结果选择它，选择过程仍然存在。
6. **“多跑几个 seed，把最好的一次报告即可。”** 这是选择偏差；应预先规定汇总规则并报告波动。
7. **“bootstrap 可以忽略数据结构。”** 重采样单位必须对应独立生成单位。
