# 对称性、群表示与等变网络

证明进阶：[T43 群平均与 attention 等变恒等式](../../proofs/deep-learning/T43-equivariance-symmetry.md) · [T44 消息传递 GNN 与 1-WL](../../proofs/lower-bounds-expressivity/T44-message-passing-wl.md)。

先用一句人话抓住主题：

> 对称性不是“图案看起来很整齐”，而是对输入做某种允许的变换后，问题的含义按可预测方式保持不变；等变网络把这种可预测关系写进了模型结构。

如果一只猫向右平移，分类答案仍应是“猫”；如果一张分割图旋转，输出掩码也应跟着旋转。前者需要**不变性**，后者需要**等变性**。群论负责整理“允许哪些变换”，群表示负责说明“特征怎样随变换移动”。

## 1. 先分清：不变与等变

设 $g$ 表示一个输入变换，例如平移、旋转、反射或重排。

### 1.1 不变性：输入变了，答案不变

若模型 $f$ 满足

$$
f(g\cdot x)=f(x),
$$

就称它对 $g$ 不变（invariant）。图像分类常希望：目标在画面中小幅移动，类别不变。集合级预测常希望：输入元素顺序改变，集合属性不变。

### 1.2 等变性：输入怎样变，输出就按规则怎样变

更一般地，输入空间和输出空间可以有不同的变换规则 $\rho_{\text{in}}(g)$ 与 $\rho_{\text{out}}(g)$。若

$$
f\bigl(\rho_{\text{in}}(g)x\bigr)
=\rho_{\text{out}}(g)f(x),
$$

就称 $f$ 等变（equivariant）。图像分割中，输入向右平移 5 像素，预测掩码也应向右平移 5 像素。

不变性可以看成特殊等变性：输出变换恒等于“不动”。但在需要位置、方向或姿态的任务里，过早把变换信息抹掉会损害预测，所以不能一概追求不变。

### 1.3 一个实用判断

先问任务输出是什么：

- 类别、全局属性：通常希望对某些变换不变；
- 分割图、关键点、光流、力或姿态：通常希望输出跟着输入等变；
- 文本序列：调换 token 往往会改变含义，因此不能对任意排列不变。

## 2. 群：可组合、可撤销的一套变换

一组变换 $G$ 若满足下面四条，就构成群：

1. **封闭**：连续做两个允许变换，结果仍在 $G$ 中；
2. **结合**： $(g_1g_2)g_3=g_1(g_2g_3)$；
3. **单位元**：存在“不做任何事”的 $e$；
4. **逆元**：每个变换 $g$ 都能由 $g^{-1}$ 撤销。

这不是为了背四条公理。它们保证“变换可以连做、可以回退，组合顺序有一致解释”，从而能稳定地讨论模型如何响应。

常见例子：

| 群 | 变换 | AI 中的场景 |
|---|---|---|
| $\mathbb Z$ 或 $\mathbb Z^2$ | 离散平移 | 序列、一维信号、像素网格 |
| $C_4$ | 旋转 $0,90,180,270$ 度 | 方形网格上的离散旋转 |
| $SO(2)$ | 平面中任意角度旋转 | 方向连续变化的二维数据 |
| $SE(2)$ | 平移 + 旋转 | 平面刚体运动 |
| $SO(3)$、 $SE(3)$ | 三维旋转、刚体运动 | 相机姿态、分子、机器人 |
| $S_n$ | $n$ 个对象的排列 | 集合或图节点重新编号 |

并非所有数据增强都构成群。例如裁剪通常不可逆，颜色抖动也未必在选定参数范围内封闭。这时仍可讨论增强带来的鲁棒性，但不能不加说明地套用全部群论结论。

## 3. 群作用与群表示：变换具体怎样落在数据上

“旋转 90 度”是抽象群元素；把一张图真的旋转，叫群对数据空间的**作用**。

当特征是向量时，经常用矩阵表示作用：

$$
\rho(g)x.
$$

若这些矩阵保留群的组合规则

$$
\rho(g_1g_2)=\rho(g_1)\rho(g_2),
\qquad \rho(e)=I,
$$

就称 $\rho$ 为群表示。它把抽象变换翻译成线性代数。

一个二维向量旋转 $\theta$ 的表示就是

$$
\rho(\theta)=
\begin{bmatrix}
\cos\theta&-\sin\theta\\
\sin\theta&\cos\theta
\end{bmatrix}.
$$

不同特征可以有不同“类型”：

- 标量温度在旋转坐标系时不变；
- 速度向量要跟着旋转；
- 二阶张量按另一套规则变化。

等变网络必须知道每类特征应该怎样变，而不是把所有通道都当作普通标量。

## 4. 为什么普通卷积天然连接平移等变

令平移算子为

$$
(T_a x)[u]=x[u-a].
$$

对卷积

$$
(x*h)[u]=\sum_v x[v]h[u-v],
$$

可以换元得到

$$
(T_ax\ast h)[u]
=(x\ast h)[u-a]
=T_a(x\ast h)[u].
$$

所以“先平移再卷积”和“先卷积再平移”给出同一结果。这是卷积核共享位置带来的结构，不只是通过数据学到的偶然现象。

但“CNN 严格平移等变”有边界：

- 零填充让图像边缘和内部的环境不同；
- stride 与下采样只对某些整数位移保持一致，且可能混叠；
- pooling、裁剪和 resize 会改变变换规则；
- 最后的全局池化常把等变特征汇总成近似不变表示。

因此论文中最好明确：理论等变针对什么网格、边界和子群，实验鲁棒性又是在什么变换范围内测量。

## 5. 从平移卷积推广到群卷积

普通卷积是在平移群上共享同一个模板。若希望同时处理旋转或反射，可以把特征定义在更一般的群 $G$ 上。离散情形的一种群卷积写法是

$$
(f*\psi)(g)
=\sum_{h\in G}f(h)\psi(g^{-1}h).
$$

$g^{-1}h$ 表示“从当前姿态 $g$ 看，位置/姿态 $h$ 在哪里”。这个相对关系使核在群的不同位置共享，并可推出对群作用的等变性。

对连续旋转、三维空间或球面，积分、采样和特征类型会更复杂。steerable CNN 常利用群表示把滤波器限制在满足等变约束的空间里。代价通常是更复杂的实现、更多姿态通道或更严格的数据假设；它不是对所有视觉任务都自动优于普通网络。

## 6. 数据增强与等变结构：两种不同的归纳偏置

假设训练时随机旋转图像并保持类别标签不变，数据增强在告诉模型：“这些旋转样本应有相同答案。”它通常是**用有限样本鼓励**近似不变性。若任务输出是分割 mask、关键点或姿态，标签也必须按同一个群作用同步变换，此时鼓励的是 equivariance，而不是输出不变。

等变架构则把

$$
f(gx)=\rho(g)f(x)
$$

写进计算结构，在规定的离散化和数值误差范围内提供更强保证。

| 方法 | 优点 | 局限 |
|---|---|---|
| 数据增强 | 简单、适配已有网络、可覆盖非群变换 | 只采有限变换；不保证精确；增加训练成本 |
| 等变架构 | 样本效率可能更高；规律更明确 | 实现复杂；选错对称性会限制模型；离散化有误差 |
| 两者结合 | 可同时使用结构先验和额外扰动 | 仍需消融，不能默认收益相加 |

最关键的问题不是“能不能加旋转增强”，而是：**这个变换在真实任务中是否应该保持标签或按已知规则改变输出？** 把数字 `6` 旋转 180 度可能变成另一个含义；自然语言中的词序更不应被当作任意对称。

## 7. Transformer：没有位置时为何会对排列等变

把 token 按行组成 $X\in\mathbb R^{n\times d}$。若没有位置编码和顺序相关 mask，自注意力为

$$
\mathop{\mathrm{Attn}}(X)
=\mathop{\mathrm{softmax}}\negthinspace\left(
\frac{XW_Q(XW_K)^\top}{\sqrt{d_k}}
\right)XW_V.
$$

用排列矩阵 $P$ 同时重排输入行，便有

$$
Q'=PQ,\quad K'=PK,\quad V'=PV,
$$

注意力矩阵变成原矩阵的行列共同重排，最终

$$
\mathop{\mathrm{Attn}}(PX)=P\mathop{\mathrm{Attn}}(X).
$$

也就是输出会以相同方式重排。这是排列**等变**，不是“语言模型天然理解顺序”。位置编码和 causal mask 正是在加入或保留顺序结构；任意排列通常不会保留 causal mask，因此上面的结论不能直接套到 decoder-only LLM。

RoPE 还可以从群表示理解：整数位置相加构成平移群，二维旋转满足

$$
R(m+n)=R(m)R(n),
\qquad R(m)^\top R(n)=R(n-m).
$$

于是位置平移被表示为特征平面里的旋转，注意力内积自然看到相对位移。细节见 [RoPE 的旋转视角](%E5%A4%8D%E6%95%B0%E3%80%81%E5%82%85%E9%87%8C%E5%8F%B6%E5%8F%98%E6%8D%A2%E3%80%81%E5%8D%B7%E7%A7%AF%E4%B8%8E%E9%A2%91%E5%9F%9F.md#53-rope%E6%8A%8A%E4%BD%8D%E7%BD%AE%E5%86%99%E6%88%90-querykey-%E5%B9%B3%E9%9D%A2%E9%87%8C%E7%9A%84%E6%97%8B%E8%BD%AC)。

## 8. CV 中还会遇到哪些对称性

1. **分类与检测。** 分类可能追求对小平移、某些尺度变化近似不变；检测框和关键点必须跟着物体移动，属于等变目标。
2. **三维视觉。** 点云、分子或机器人中的整体旋转、平移常由 $SE(3)$ 描述。标量、向量和高阶特征必须按正确表示变换。
3. **图神经网络。** 节点编号本身通常没有意义，所以重编号后节点输出应相同重排，图级汇总应不变。
4. **ViT。** patch token 的注意力若无位置结构，对 patch 排列等变；二维位置编码会告诉网络哪些 patch 相邻。它不是天然拥有 CNN 那样的局部平移先验。
5. **测试时增强。** 对多个变换预测再平均，可近似“群平均”以提高不变性，但计算更贵，也可能把本应保留的方向信息平均掉。

## 9. 可运行示例：无位置自注意力的排列等变

```python
import numpy as np

rng = np.random.default_rng(7)
X = rng.normal(size=(5, 4))
Wq = rng.normal(size=(4, 3))
Wk = rng.normal(size=(4, 3))
Wv = rng.normal(size=(4, 2))

def softmax_rows(scores):
    scores = scores - scores.max(axis=1, keepdims=True)
    weights = np.exp(scores)
    return weights / weights.sum(axis=1, keepdims=True)

def attention_without_position(tokens):
    Q, K, V = tokens @ Wq, tokens @ Wk, tokens @ Wv
    weights = softmax_rows(Q @ K.T / np.sqrt(Q.shape[1]))
    return weights @ V

# P 同时重排全部 token；没有位置编码，也没有 causal mask。
order = np.array([2, 4, 0, 3, 1])
P = np.eye(len(X))[order]

original = attention_without_position(X)
permuted = attention_without_position(P @ X)

print("equivariance error:", np.max(np.abs(permuted - P @ original)))
print("invariant pooled error:",
      np.max(np.abs(permuted.mean(axis=0) - original.mean(axis=0))))

assert np.allclose(permuted, P @ original)
# 对等变输出做对称的 mean 汇总，得到排列不变的全局表示。
assert np.allclose(permuted.mean(axis=0), original.mean(axis=0))
```

可以尝试给每一行加一个固定位置向量，再重复实验：任意重排 token 内容却不相应重排位置时，等变关系会被有意打破。

## 常见误区

1. **“不变总比等变更鲁棒。”** 对关键点、分割和姿态，输出必须保留变换信息；错误的不变性会丢掉任务所需信号。
2. **“用了数据增强，就保证了不变性。”** 有限增强通常只鼓励模型近似满足规律，未提供对所有变换的严格保证。
3. **“所有增强都是群。”** 裁剪、遮挡、不可逆颜色变换可能没有逆元或不封闭。
4. **“卷积在实际 CNN 中无条件严格平移等变。”** 边界、stride 和下采样都可能破坏结论。
5. **“无位置 Transformer 对排列不变。”** token 级输出是同样重排，即排列等变；只有对 token 做对称汇总后才可能得到不变输出。
6. **“LLM 应对任意 token 排列不变。”** 词序通常承载意义；位置机制是在刻意打破或组织这种对称。
7. **“发现一种真实世界对称性，就一定该硬编码。”** 数据采集、边界条件、标签定义可能只近似满足它；错误先验会降低表达能力。

## 自测

1. 分类、语义分割和关键点检测分别更需要不变还是等变？为什么？
2. 群的逆元在“可撤销变换”中扮演什么角色？裁剪为何通常不是群元素？
3. 用一句话解释群表示为什么是“抽象变换到矩阵”的翻译器。
4. 推导一次 $T_a(x\ast h)=T_ax\ast h$，并指出真实 CNN 中哪三处可能破坏它。
5. 为什么无位置、无 mask 的 self-attention 是排列等变，而不是排列不变？
6. 数据增强和等变架构分别把先验放在了哪里？怎样设计消融比较它们？
