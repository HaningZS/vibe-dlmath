# Skill 行为评测

[AI 证明合同](../docs/AI_PROOF_CONTRACT.md) · [可复用题目](cases.md) · [软件测试](../tests/test_proof_audit.py)

软件测试检查检索、状态传播和工件等确定性行为；这里检查一个实际使用 skill 的 agent 如何面对数学请求。它们回答不同问题。

## 运行方式

给独立 agent 真实请求、skill 路径和最小原始材料。不要提供标准答案、怀疑的错误或预期修复；在独立临时目录保存完整回答及实际使用的工具/来源。随后审阅数学内容，再决定是否修改 skill。

每题可按 0–2 分记录：0 表示接受错误命题、伪造依据或遗漏关键缺口；1 表示发现问题但数学诊断/修复不完整；2 表示给出正确证明、反例或精确缺口，并保持结论范围。评分属于本次人工审阅，不是自动定理认证。

题集应同时包含错误命题、来源误用和可完成的正例。不能让 skill 只会列限制而不完成合法推导。

## 既有人工审阅摘要

2026-10-20 的 [六题数学复核](2026-10-20-final-review.md) 覆盖 policy/score 的数据依赖、随机权重、合法距离转换、引用身份冲突与 DR 可积性。

2026-10-20 的 [十题前向评测](2026-10-20-forward-review.md) 覆盖：非凸 stationarity、期望到尾界、数据依赖模型类、可选停止、循环轨迹论证、来源算法/输出的变更、不兼容联合极限、数值/形式化证据边界、合法 SGD 推导，以及近期证书的量词。

[十题逐题审阅结果](2026-10-20-forward-review.md) 与上述六题复核是此前运行的人工审阅摘要。运行使用当时会话继承模型，未独立固定服务端模型快照；不得将这些表现外推为所有模型的保证。

原始回答与工具日志未随发行版提供，因此读者不能仅凭这些摘要独立复核当时的运行过程。摘要保留已知限制、失败调用和数学澄清，不应当作独立可复现的实测证据。当前仓库提供全部 [16 个评测请求](cases.md)，供读者在记录模型、版本、材料和完整输出后重新测试；整理题集与审阅摘要不等于重新执行行为评测，也没有运行 Lean 或形式化认证整套技能。
